# Расчёт глобальной освещённости фотометрического шара

Лабораторная работа № 1 по курсу «Системы компьютерной обработки изображений»
(Университет ИТМО, факультет ПИиКТ).

Авторы: Маргиев Давид, Хайцын Олег (группа P3469).

## Описание

Программа рассчитывает освещённость внутренней поверхности сферы с точечным
изотропным источником в центре методом переноса лучистой энергии
(radiosity) и сравнивает результат с аналитическим решением.

- Поверхность шара разбивается на `nz × nphi` участков равной площади
  (по умолчанию 4 × 8 = 32).
- Форм-факторы между участками вычисляются трассировкой лучей
  (метод Монте-Карло с косинусным распределением направлений). Для сферы
  точное значение равно `1/N`, так что погрешность трассировки видна напрямую.
- Освещённость находится итерациями `E = E0 + ρ·Fᵀ·E` и прямым решением
  линейной системы, после чего сравнивается с точным значением
  `E* = E0 / (1 − ρ)`, где `E0 = Φ / (4πR²)`.
- Дополнительно рассчитываются наборы параметров A–E, в каждом из которых
  меняется одна величина: радиус, световой поток или коэффициент отражения.

Исходные данные: `R = 2 м`, `ρ = 0,9`, `Φ = 1000 лм`, 100 000 лучей на участок.
Они, как и `seed` генератора случайных чисел, задаются в начале `calculate.py`.

## Запуск

Нужны Python 3 и NumPy.

Через виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
pip install numpy
python calculate.py
```

Или через [uv](https://docs.astral.sh/uv/), без создания окружения:

```bash
uv run --no-project --with numpy python calculate.py
```

На дистрибутивах, где системный Python защищён (Arch, Manjaro, Debian 12+ и др.),
`pip install` вне виртуального окружения завершится ошибкой
`externally-managed-environment`. Используйте один из способов выше.

## Результаты

Скрипт печатает сводку в консоль и сохраняет рядом с собой:

| Файл | Содержимое |
| --- | --- |
| `form_factors.csv` | Матрица форм-факторов `N × N` |
| `iterations.csv` | Итерации для базового набора параметров |
| `all_cases.csv` | Итерации для наборов A–E |
| `case_summary.csv` | Параметры наборов и число итераций до погрешности 1 % и 0,1 % |
| `tables.tex`, `cases_*.tex` | Фрагменты таблиц LaTeX для отчёта |

Эти файлы генерируются заново при каждом запуске и в репозиторий не добавляются.

Основные результаты для базового набора: истинная освещённость 198,9437 лк
(в 10 раз больше прямой), относительная СКО решения с форм-факторами
трассировки около 0,305 %.
